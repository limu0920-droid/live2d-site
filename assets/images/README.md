# 图片替换说明

这些 SVG 是上线前可用的临时占位素材，避免页面破图。

后续客户提供正式图片时，建议直接替换同名文件，或在 HTML 中把路径改成新的图片文件：

- `hero-bg.svg`：首页主视觉
- `works/work-01-thumb.svg`：首页/作品页角色作品 01
- `works/work-02-thumb.svg`：首页/作品页角色作品 02
- `works/work-03-thumb.svg`：首页视频入口封面
- `works/scene-01-thumb.svg`：场景作品封面
- `works/live2d-01-thumb.svg`：Live2D 作品封面
- `links/link-character-01.svg`：视频合集角色视频封面
- `links/link-scene-01.svg`：视频合集场景视频封面

推荐正式图片格式：`.webp` 或 `.jpg`。如果改文件名，需要同步修改 HTML 里的 `src`。
