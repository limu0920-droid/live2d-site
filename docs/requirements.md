# 需求文档

## 项目目标

为客户搭建可公开访问的个人展示网站，用于展示 3D/Live2D 相关作品、公开视频、委托说明和联系方式。

## 页面范围

1. 首页 `index.html`
   - 展示个人品牌、服务方向、精选作品入口、委托说明。
   - 首页保留 Live2D 展示位。
2. 作品页 `works.html`
   - 展示图片作品和视频作品封面。
   - 视频默认跳转外部平台观看。
3. 视频合集页 `links.html`
   - 按系列整理外链视频。
   - 使用本地封面图提升视觉一致性。

## 媒体类型

- 图片：本地静态资源。
- 外链视频：使用封面卡片跳转外部平台。
- Live2D：模型文件放入 `assets/live2d/` 后由前端脚本加载。

## 维护方式

- 不做 CMS/后台。
- 后续图片、视频链接、文案由开发者维护代码。
- 替换图片时优先保持原文件名，减少 HTML 改动。

## 上线要求

- 页面可公开访问。
- 三页导航正常。
- 图片不破图。
- 外链视频能打开。
- Live2D 未提供模型前显示待接入状态，不影响页面浏览。
- 不出现本地绝对路径。

## 非目标

- 不实现客户自行上传图片后台。
- 不默认自托管大体积视频文件。
- 不改变现有页面布局。
