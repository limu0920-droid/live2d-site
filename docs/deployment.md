# 部署说明

## 项目类型

纯静态网站，无需安装依赖、无需构建。

## 可选平台

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel 静态站
- 普通静态服务器

## 部署目录

部署项目根目录即可，确保根目录包含：

```text
index.html
works.html
links.html
assets/
docs/
```

## 上线检查

- 首页可访问。
- `works.html`、`links.html` 可通过导航进入。
- 所有图片加载正常。
- 外链视频可以新标签打开。
- Live2D 未接入模型时不报阻断错误。
- 源码中没有 `C:\`、`D:\` 等本地路径。
- 移动端页面不横向溢出。

## 缓存注意

如果替换了图片但线上没变化，可能是浏览器或平台缓存。可采用：

- 清理平台缓存。
- 改图片文件名并同步更新 HTML。
- 等待 CDN 缓存刷新。

## Live2D 注意

Live2D 模型目录必须完整上传。若控制台出现 404，优先检查模型 JSON、贴图、动作文件路径是否与模型 JSON 内部引用一致。
