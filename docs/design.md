# 设计文档

## 视觉方向

网站保持现有“纸感底色 + 朱红点缀 +  serif 标题”的东方质感风格。布局不调整，只在原有占位区域内替换真实媒体。

## 页面结构

### 首页

- 顶部导航固定。
- 左侧为品牌说明和入口链接。
- 右侧为主视觉图。
- 下方三张精选作品卡片承接作品页和视频合集页。
- 委托区保留当前信息面板结构。

### 作品页

- 保留顶部统计、筛选条和大卡片布局。
- 左侧媒体区显示封面图。
- 右侧信息区显示标题、类型、时间、备注。
- 点击卡片打开外部视频平台。

### 视频合集页

- 保留系列分组和大卡片布局。
- 左侧显示封面图与平台角标。
- 右侧显示委托/制作信息。

## 图片规则

- 首页主视觉：竖图优先，建议比例接近 4:5 或 3:4。
- 作品页封面：横图优先，建议比例 16:10 或 3:2。
- 视频合集封面：大横图，主体居中，避免边缘重要信息被裁切。
- 正式上线建议使用 `.webp` 或压缩后的 `.jpg`。

## Live2D 展示规则

- Live2D 作为首页右下角浮层，不参与页面排版，避免改变布局。
- 移动端隐藏，防止遮挡内容。
- 模型未接入时显示“Live2D 模型待接入”。

## 外链规则

- 外链视频在新标签页打开。
- 链接需要使用 `rel="noopener noreferrer"`。
- 不默认嵌入第三方 iframe，避免拖慢首页和作品页加载。
